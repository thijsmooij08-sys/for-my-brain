# Strategy system

Strategies only analyze normalized snapshots and return versioned, explainable Signals. The Phase 1 DevelopmentStrategy is explicitly **NOT A VALIDATED PROFIT STRATEGY**. An Opportunity is produced only from an actionable Signal and carries fair probability, executable price, costs, liquidity/depth, age, confidence, and explainable rationale.

Future strategies may consume fused intelligence, but every component estimate,
confidence, disagreement measure, evidence reference, model version, edge
confidence, execution confidence, and model-agreement value remains visible.
Intelligence modules produce research outputs; they do not place orders.

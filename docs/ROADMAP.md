# Roadmap

Phase 1 — **Safe Foundation** — COMPLETE: public discovery/order books, canonical domain, SQLite persistence, development strategy, sizing/risk, realistic paper execution/accounting, API/dashboard, and validation. No live trading.

Phase 2 — **Data Foundation** — COMPLETE: public streaming, book maintenance, reconnects, lifecycle updates, data-health monitoring, provider abstractions, point-in-time storage, evidence records, provenance, and event timestamps.

Phase 3 — **Research / Simulation Foundation** — COMPLETE: deterministic replay, dataset manifests, point-in-time feature access, exact-decimal book-walking fills, fee/slippage/latency models, scenario shocks, backtest metrics/artifacts, research statistics, and multiple-hypothesis protection.

Phase 4 — **Intelligence Lab** — COMPLETE: evidence-backed fundamental, valuation, peer, technical, earnings, macro, event-study, pattern, income, signal-fusion, and Polymarket event-graph research outputs. No intelligence output executes or authorizes capital.

Phase 5 — **Autonomous Paper Intelligence** — COMPLETE: a controlled Polymarket paper loop now performs SCAN → ANALYZE → RANK → SIZE → RISK → PAPER BUY → MANAGE → PAPER SELL → ACCOUNT → REVIEW with freshness/provenance eligibility, book-walking fills, deterministic risk, kill-switch protection, persistent cycle idempotency, and review journaling. No live execution.

Phase 6 — **Adaptive Learning** — COMPLETE: immutable paper-trade attribution, Decimal calibration, content-addressed registries, feature ablation, counterfactual evaluation, Champion/Challenger gates, append-only promotion/rollback records, and research-only allocation artifacts. Learning cannot bypass deterministic risk or authorize execution.

Phase 7 — **Shadow Forward Validation** — COMPLETE: forward-test competing models and signal-fusion methods using current data without orders.

Phase 8 — **Live-Readiness Engineering** — COMPLETE: redacted authenticated-capability contracts, account synchronization, user-stream health, deterministic reconciliation, eligibility, circuit breakers, restart-safe paper state, and a fail-closed execution state machine. Real order submission remains disabled.

Phase 9 — **Limited-Live Preparation** — COMPLETE: production-like account/reconciliation contracts, operational preflight, redacted rehearsal, and explicit authorization gates are implemented; real-order submission remains disabled by default.

Phase 10 — **Adaptive-Live Architecture** — COMPLETE: research-only adaptive allocation, promotion, rollback, hash-chained audit, API, and adversarial control surfaces are implemented. Learning cannot alter deterministic risk or authorize live execution.

Phases 8+ — **Live readiness and limited live operation** — only after explicit future authorization, independent gates, eligibility, reconciliation, and production risk controls.
